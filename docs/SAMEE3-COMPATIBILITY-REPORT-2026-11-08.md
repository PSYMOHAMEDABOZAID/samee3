2. **مشروع macOS مستقل:** `native/macos/` بمحتوى المصحف وحزمة Electron وملفات التحقق.
3. **مشروع Windows مستقل:** `native/windows/` بمحتوى المصحف وملفات Electron والاختبارات.
4. **مشروع Android TV قديم مستقل:** `native/android-tv/` يستهدف Android 5 أو أحدث حسب تكوين المصدر؛ البناء والتشغيل على الأجهزة الحقيقية لم يتم التحقق منهما بعد.

6. **أوامر البناء المحلي الاختيارية:** `BUILD-LOCAL/` و`BUILD-APK-LOCAL-MAC.command`؛ لا تعمل تلقائيًا بمجرد الرفع.

1. فك ضغط الملف. **لا ترفع ZIP نفسه إلى GitHub متوقعًا أن يستخرج محتواه.**
2. تأكد أن لديك أحدث نسخة من المستودع، وأن SHA لفرع `main` لم يتغير منذ `3764a178d20b78c466cb4343c394c39a20298032`. إن تغيّر، أعد فحص `lib/persistent-player.ts` قبل الاستبدال.
3. أنشئ فرعًا جديدًا باسم `fix/samee3-compatible-20261108` من GitHub Desktop أو GitHub مباشرة.
