## محتويات الحزمة

1. `lib/persistent-player.ts` — الملف الكامل الجاهز للاستبدال في نفس مساره. الإصلاح الوحيد فيه هو التحقق من وجود `document` قبل الوصول إلى `document.visibilityState` أثناء حدث `pause`، بحيث ينجح الاستخدام من بيئات الاختبار التي ليس بها DOM. لا يحذف وظائف أو ميزات الصوت الحالية.
2. `docs/SAMEE3-AUDIT-2026-11-08.md` — تقرير المراجعة هذا للاحتفاظ به داخل المستودع.
3. `اقرأني-قبل-الرفع.txt` — تعليمات مختصرة وواضحة للرفع.

**مهم:** رفع ملف ZIP نفسه إلى المستودع لا يطبق الإصلاح؛ يجب **فك ضغطه** ثم رفع الملفات إلى مساراتها نفسها. لا تستبدل مجلد `lib` بالكامل، ولا تحذف أي ملفات من المشروع.

## طريقة الرفع الآمنة — من دون تشغيل GitHub Actions يدويًا

1. افتح المستودع على GitHub في المتصفح وأنشئ فرعًا جديدًا من `main` باسم `audit/samee3-stability-2026-11-08` (إن لم يكن موجودًا). لا ترفع على `main` مباشرة.
2. فك ضغط ZIP على جهازك.
3. اختر الفرع الجديد ثم افتح المجلد `lib` وارفع **فقط** `persistent-player.ts` الموجود في ZIP بدل الملف القديم. استخدم رسالة commit: `fix(audio): guard DOM access in headless playback tests`.
4. افتح `docs` في الفرع الجديد وارفع `SAMEE3-AUDIT-2026-11-08.md`.
5. افحص نتائج الاختبارات على GitHub ثم أنشئ Pull Request من الفرع الجديد إلى `main` للمراجعة. **لا تضغط Merge** قبل نجاح الاختبارات.

إن وجدت أن الملف `lib/persistent-player.ts` تغير في المستودع منذ الالتقاط المرجعي، **لا تستبدله مباشرة** قبل مقارنة النسختين، حتى لا تُفقد تعديلات أحدث.
