## تجربة الأذكار الجديدة

- اختيار القارئ بالبحث، مع عدد المقاطع المتاحة للباب الحالي وتوضيح وجود تسجيل كامل.
- عرض «ذكر واحد» بأزرار السابق والتالي، أو عرض القائمة كاملة؛ يبقى النسخ والمصدر والمفضلة وصورة الذكر والعدّاد متاحًا.
- من «التكرار والسرعة والتنزيل»: اختر «مرة واحدة»، أو «حسب العدّاد» لتشغيل المتبقي، أو «عدد أختاره» من 1 إلى 1000، مع اختصارات 3 و7 و10 و33 و100.
- لكل ذكر في قائمة التشغيل ميزانية تكرار مستقلة. يمكن إعادة الاستماع إلى ذكر مكتمل بالعدد المختار، ويقف عدّاد الإنجاز عند صفر. تبقى الأعداد الأصلية المكتوبة مع الذكر كما هي.
- زر «استمع لهذا الذكر» يشغل هذا الذكر وحده؛ زر تشغيل المتبقي أو كل المتاح يشغل الأذكار بالتتابع. يتبع العرض الذكر الجاري.
- حفظ إعدادات القراءة والعرض الليلي والتكرار، وتحسين ألوان القراءة الليلية. تصفية «الصوت المتاح» تعتمد الآن على القارئ المختار وصيغة الصباح/المساء الفعلية.
- استمرار الصوت وتسلسل الأذكار عند التنقل داخل التطبيق، مع مشغل صغير للعودة إلى الورد. استمرار الصوت أثناء التنقل لا يضمن منع نظام الهاتف من إيقاف المتصفح في الخلفية.
- نصوص محلية ونسخة محفوظة للأذكار، وتنزيل للصوتيات مع استكمال محاولات الأجزاء المنقطعة، وتشغيل محفوظ دون إنترنت. لا تُحمّل المجموعة الصوتية الضخمة تلقائيًا عند التثبيت.

تضم الحزمة أيضًا إصلاحات الإصدار السابق للمكتبة الصوتية وروايات العفاسي ومشاركة المشغل على مستوى التطبيق، ومعالجة تحميل الملفات الكبيرة دون تجميعها كلها في ذاكرة الصفحة، وتحسين حقول أوقات الإشعارات وتشخيص مفاتيح VAPID.

## الرفع مرة واحدة

1. فك الضغط وادمج مجلدات الحزمة في جذر مشروع `samee3` الموجود، واستبدل الملفات المطابقة.
2. ارفع الملفات الصوتية والكود معًا باستخدام GitHub Desktop أو Git. لا ترفع ZIP نفسه داخل `public`.
3. نفّذ `npm ci` ثم `npm test` و`npm run build`، أو ارفع للفرع المرتبط بـVercel لينفذ البناء المعتاد.
4. بعد نجاح النشر افتح `/adhkar`، و`/adhkar/recordings`، و`/developers/adhkar`.

هذه حزمة دمج كاملة للتحديث وليست مشروع Next.js مستقلًا. لا تحتاج نماذج تعرف أو سكربتات تجهيز أو إعادة تنزيل التسجيلات لتشغيلها. المسارات تصبح متاحة على موقعك بعد نشر الكود والملفات. لا تُغيّر الحزمة إعدادات Firebase أو مفاتيح الخادم؛ خدمة الإشعارات تستخدم إعداداتها الحالية.

## التوقيتات وفصل الأذكار

كل ملف فردي يبدأ عند صفر وينتهي بمدته المقاسة. يشير `source` إلى موضعه في التسجيل الأصلي المحدد ببصمته. تتضمن ملفات التوقيتات العناصر والصيغ `variants` والتسجيلات الكاملة `sections`.

المجموعة تضم 267 ملفًا نشره المصدر أصلًا لكل ذكر، و160 ملف باب يقابله عنصر واحد في فهرس سميع، و751 مقطعًا فُصل بمطابقة النص وتوقيت الكلمات من صوت القارئ نفسه. بعض الملفات الأصلية قد تشمل عنوان الباب أو تكرار الدعاء داخليًا.

الحدود الآلية تحمل `manuallyReviewed=false` ولم تُراجع كلها باستماع بشري. قد يقتصر المقطع على الدعاء أو الآيات المقتبسة دون التعليمات التحريرية؛ يوضح `matchedText` و`textMatchScope` النطاق. لم تُقسّم مدة التسجيل بالتساوي ولم تُنسخ توقيتات قارئ آخر. لم تُنشأ أصوات مقلدة أو نصوص أذكار بالتعرف الصوتي.

استُبعد المصدر 520 (دعاء الذهاب إلى المسجد لمصطفى وليد) بسبب أخطاء متكررة بفك إطارات MP3، وبقي تسجيله السليم لأذكار الاستيقاظ. المقاطع التي لا تجتاز المطابقة لا تُضاف فرديًا، وتبقى تسجيلات مصادرها السليمة الكاملة متاحة.

## للمطورين

بعد النشر يمكن قراءة البيانات وتنزيل الصوتيات دون تسجيل أو مفتاح:

```text
/api/adhkar/v1
/api/adhkar/v1/reciters
/api/adhkar/v1/items?reciter=mishary-alafasy&category=1&section=morning
/api/adhkar/v1/sections
/api/adhkar/v1/timings/mishary-alafasy
/data/adhkar-audio/v1/catalog.json
```

CORS وطلبات Range مدعومان. تستخدم الروابط النسبية عنوان موقعك بعد النشر. أبقِ اسم القارئ والمصدر والحقوق؛ الإتاحة التقنية المجانية لا تمنح ترخيصًا تجاريًا عامًا لكل التسجيلات. مصادر TVQuran تحمل شرط عدم الاستخدام التجاري، وباقي المواد تتبع حقوق أصحابها المبينة في الفهرس.
