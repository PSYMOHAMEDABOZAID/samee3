# مصحف سميع — تظليل الآيات على النسخة الخفيفة

## ماذا أضفنا؟

- **التظليل الآلي آيةً بآية** أثناء تشغيل **مشاري العفاسي — المصحف المجمّع**، باستخدام `/api/alafasy-timings/[surah]` الخاص بهذا التسجيل بالذات (التوقيت بالمللي ثانية).
- لون ذهبي هادئ للآية النشطة، وظل خفيف، وتلوين أخضر مستقل للآية التي يختارها المستخدم.
- الضغط أو Enter على الآية للانتقال إلى توقيتها داخل **نفس ملف المصحف المجمّع**، دون تشغيل الملف تلقائيًا من دون ضغطة المستخدم.
- متابعة تلقائية للآية على الشاشة مع زر لتفعيلها أو إيقافها.
- بدء السماع من **أول آية ظاهرة** في الصفحة عند توفر توقيتها، أو خيار «تشغيل السورة من البداية».
- في الصفحات التي تضم آيات من سورتين تظهر قائمة لاختيار **السورة المسموعة** بدل مزج توقيت سور مختلفة.
- عند غياب التوقيتات، أو عدم تطابقها، **لا توجد محاكاة مضللة للتزامن**. تبقى القراءة والصوت واختيار الآية يدويًا متاحة.
- عند اختيار قارئ غير العفاسي المجمّع: يعمل صوته كما في الإصدار السابق، ويظل تحديد الآية اليدوي متاحًا، لكن **التظليل الصوتي الآلي ليس مفعّلًا لهذا القارئ** إلى حين توفر توقيتات *مطابقة لنفس التسجيل*.
- صفحات الروايات غير حفص لا يُشغّل عليها صوت حفص ولا يفرض عليها توقيتاته.
- HTML الأساسي وملف MP3 وروابط الصفحات لا تحتاج إلى JavaScript؛ التظليل الإضافي وحده يحتاج دعم JavaScript العادي و XMLHttpRequest و HTMLMediaElement.currentTime.

## المسارات المطلوب رفعها / استبدالها

**يكفي تحديث ملفين فقط لو ركبت حزمة التوافق السابقة بالفعل:**

1. `app/api/legacy-quran/route.ts` — **استبدال** الملف السابق كاملًا.
2. `public/legacy/ayah-highlight.js` — **إضافة** ملف جديد.

ملفان إضافيان للتوثيق والاختبار:

3. `scripts/test-legacy-highlight.cjs` — اختبار محاكاة يمكن رفعه ضمن المستودع.
4. `README-AR.md` — هذا الملف؛ اختياري رفعه.

`lib/legacy-reciters.ts` مرفق **كاعتماد مطابق للإصدار السابق**، ولا يلزم استبداله إذا كان موجودًا ومحدثًا ويحتوي `DEFAULT_LEGACY_RECITER` و `legacySurahAudioUrl`.

**لا تستبدل** `app/layout.tsx` أو `next.config.js` أو الملفات الأخرى، حتى لا تضيع أي تعديلات أحدث أجريتها بعد حزمة التوافق.

## الاختبار

بعد دمج الملفات داخل المستودع:

```bash
node scripts/test-legacy-highlight.cjs
npm run build
```

ثم بعد نجاح نشر Vercel:

- `https://samee3.vercel.app/api/legacy-quran?page=2&riwaya=hafs&reciter=alafasy-collected`
- شغّل الصوت؛ يجب أن تنتقل الإضاءة بين الآيات وفق توقيت الملف الأصلي.
- اضغط على آية من منتصف السورة؛ يجب أن ينتقل الصوت إلى وقتها عند دعم المتصفح للقفز الزمني.
- جرّب `&reciter=husary` للتأكد أن توقيتات المصحف المجمّع لا تطبّق على الحصري.
- جرّب `&riwaya=warsh` للتأكد من عدم ربط صوت حفص بالرواية الأخرى.
- جرّب تعطيل JavaScript: تظل الصفحة والنص وروابط الصفحات والصوت معروضة، ولكن التظليل الديناميكي لا يعمل.

## حدود تقنية مهمة

- إصدار المستودع يحتوي على API لتوقيتات المجمّع؛ هذا التحديث **لا ينشئ توقيتات جديدة** ولا يفترض أنها كاملة أو صحيحة لكل سورة: يتحقق من البنية والأرقام والمدة وقت التشغيل ويرفض البيانات غير المتوافقة بدل التظليل غير الدقيق.
- التظليل **على مستوى الآية**، وليس الكلمة أو الحرف، ولا توجد مزامنة الصوت عبر تغيير صفحات HTML كاملة (لأن التنقل يحمّل صفحة جديدة في المتصفحات القديمة).
- عند تشغيل السورة في صفحة لا تعرض كل آياتها، سيظهر «الآية الحالية خارج الصفحة» إلى أن يصل الصوت لآياتها. اختيار أول آية ظاهرة هو الحل الافتراضي.
- لا تضمن الاختبارات المحلية أن ملف MP3 أو توقيتات GitHub Release متاحان لحظة التشغيل، ولا تغني عن التجربة على الجهاز والمتصفح المستهدف.
- لا يلزم تغيير تصميم مصحف سميع الحديث؛ هذه الملفات تخص نسخة التوافق الخفيفة.
