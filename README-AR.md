## الرفع من دون GitHub Actions

1. فك ضغط ZIP على الكمبيوتر، وستجد المجلدات `app` و`components` و`lib` و`scripts`.
2. أنشئ فرعًا جديدًا من أحدث `main` داخل GitHub إن أمكن (للتجربة وحماية الموقع).
3. انسخ **الملفات بمساراتها الأصلية** إلى المستودع. لا تحذف أي ملفات أخرى. على الهاتف افتح المجلد المناسب ثم استخدم `Add file → Upload files` لملف ذلك المسار.
4. أكمل `Commit changes`. Vercel قد ينشر تلقائيًا عند الدمج في `main`؛ هذا **ليس** GitHub Actions.
5. في بيئة محلية فيها `node_modules` مثبتة، شغّل يدويًا إذا أردت:
   - `node scripts/verify-samee3-usage.cjs`
   - `npm run typecheck`
   - `npm test`
   - `npm run build`
6. جرّب المؤقت من `/mushaf` و`/adhkar/read` و`/audio`. شغّل تلاوة المصحف، ثم انتقل للرئيسية وتأكد من وجود شريط التلاوة. شغّل الأذكار المتتابعة وأغلق الشاشة ثم عد للتطبيق، ثم اختبر انتقال السورة التالية في المكتبة والمصحف. جرّب تسجيلات Assabile وQuran TV والعفاسي أثناء الاتصال ودون إنترنت.
7. راقب **Vercel → Usage → Fast Origin Transfer** لمدة يوم أو أكثر. لا يمكن تأكيد مقدار الوفر دون بيانات الاستهلاك الفعلية. زيادة الدعم 3 أضعاف مؤقتة لمدة 30 يومًا.

## حدود مهمة

- تطبيق الويب وPWA لا يستطيعان إغلاق الهاتف أو التطبيق بالقوة؛ «إغلاق القراءة» يعني العودة للرئيسية مع إيقاف الصوت الملائم.
- عند قفل الهاتف قد يعلّق النظام JavaScript؛ في هذه الحالة قد يتأخر الإيقاف التلقائي حتى يعود المتصفح للعمل أو يبدأ إرسال أحداث الصوت. **لا يُضمن إيقاف الصوت في الثانية المحددة على جميع الأجهزة أثناء إغلاق الشاشة** من غير تنفيذ مؤقت أصلي في Android/iOS.
- لتخفيض استهلاك العفاسي مع إبقاء جميع مساراته الحالية دون تعديل، نحتاج أولًا تقرير استهلاك منفصل من Vercel، ثم حل استضافة / CDN خارجي متوافق معه. لم نغير ملفات العفاسي في هذه الحزمة.
- تم فحص صياغة ملفات TypeScript/TSX وفحوص التكامل الموضعية. لم يتم تنفيذ اختبار سمعي حقيقي على أجهزة الهاتف، ولا يمكن الجزم بعلاج كل حالات التوقف دون إعادة إنتاج المشكلة. **لم يمكن تشغيل بناء Next.js الكامل أو اختبار Android/iOS فعليًا من هذا الوسط** لأن نسخة المستودع الكاملة والحزم غير متاحتين محليًا.

## لماذا يحتاج التعديل إلى ملف سادس؟

النسخة السابقة كانت تحتوي على خمسة ملفات تعمل على الموقع، لكنها **لم تركّب** مكوّن `PersistentAudioPlayer` الموجود أصلًا في المستودع في الشريط العام. ولذلك من أجل عرض مشغل القرآن والأذكار والمكتبة خارج صفحاتها لازم تعديل الملف الموجود `components/PersistentAudioPlayer.tsx` بجانب الخمسة؛ التعديل لا يستبدل صفحة المصحف الكبيرة أو صفحة الأذكار الكبيرة أو المكتبة الصوتية.
